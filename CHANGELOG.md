# Changelog

## 1.0.0

- First public release of Liteyear Retro FX.
- Fifteen stackable OBS Lua video filters with GPU processing.
- Built-in Cathode Boot animation, global bypass, shader checks and effect reload.
- Neutral naming and independent filter IDs for public use.
- OBS-ready ZIP, complete editable source, build checks and setup guide.
- Original personal build confirmed working on a Mac mini.

The public release retains the same effect implementations, default values and
controls as the tested personal build. Existing personal-build filters are not
automatically migrated; they can continue using their original script.
