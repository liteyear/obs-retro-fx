First public release of **Liteyear Retro FX**, a simple OBS Lua package with
15 stackable GPU video effects.

Download **Liteyear-Retro-FX-1.0.0.zip**, unzip it, then add
**liteyear-retro-fx.lua** through **OBS → Tools → Scripts → +**.
Keep the included assets folder beside the Lua file.

Effects: Chromatic Aberration, Frame Skip, Interlace, Posterize, Dither, CRT,
NTSC, Cathode Boot, Matrix Rain, Retro Codec, VHS, Bloom, Scanlines,
Digital Glitch and Analog Glitch.

- No separate native plugin installer, Terminal setup or Python configuration.
- Global bypass, shader checks, reload and built-in Cathode Boot animation.
- Includes a setup guide, complete editable source and SHA256 checksum.
- Personal build confirmed working on a Mac mini; automated real-OBS tests
  on Linux. Windows remains untested. Exact Mac hardware/OBS version unrecorded.
- Original settings/presets are not imported; controls are streamlined.
