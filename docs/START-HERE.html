Liteyear Design · Version 1.0

Retro effects.
One folder.

15 effects inside OBS. Load the script once, then choose effects from your camera or scene’s Filters window.

No TerminalNo extra plugin installerGPU effects
1

Keep this folder together.

Move Liteyear-Retro-FX into Documents or another permanent location. Leave assets beside liteyear-retro-fx.lua.

2

Add the script to OBS.

Open the menu below, click +, and select liteyear-retro-fx.lua from this folder.

OBS → Tools → Scripts → +

Use the Scripts tab. No Python setup is needed.

3

Add an effect.

Close Scripts. Right-click your camera, video, group or scene. Open Filters, then click + under Effect Filters and pick any Liteyear FX effect.

Right-click source → Filters → + → Liteyear FX - VHS

Add more filters to combine looks. OBS saves them for next time.

Keep your current setup intact.

Turn off other retro-effect filters with their eye icons while trying these. The new filters have their own settings.

Mac user tested, with automated rendering tests on Linux. See the test report for platform details.

All the effects

Chromatic Aberration · Frame Skip · Interlace · Posterize · Dither · CRT · NTSC · Cathode Boot · Matrix Rain · Retro Codec · VHS · Bloom · Scanlines · Digital Glitch · Analog Glitch

Need the original picture back?

Click the eye beside an effect to turn it off. To bypass everything at once:

Tools → Scripts → liteyear-retro-fx.lua → Bypass every Liteyear FX filter

If something does not show up

Select the script in Tools → Scripts and click Check all 15 effects. Click Reload effects to retry. A missing Matrix font usually means the assets folder was moved.

Cathode Boot starts at 0% (normal picture). Set its progress or select a built-in animation to see the collapse effect.
